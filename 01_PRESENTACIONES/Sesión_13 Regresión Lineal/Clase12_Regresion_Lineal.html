El problema

Eres analista en la Secretaria de Hacienda. Tu director te pide: “Necesito predecir el ingreso fiscal de los 2,469 municipios para los proximos 3 anos.”

Si tienes un buen modelo puedes:

• Presupuestar transferencias federales
• Detectar anomalias (fraude fiscal)
• Evaluar politicas (¿becas impactan ingreso?)

El reto:

Tienes 50 variables candidatas. ¿Las usas todas?
OLS clasico usaria todas, pero sobreajustaria: perfecto en training, falla en datos nuevos.

Solucion: La regresion lineal como herramienta de prediccion + regularizacion. Eso es lo que aprenderemos hoy.

¿Que es la regresion lineal?

Es un modelo que busca la mejor recta (o hiperplano) que describe la relacion entre una variable dependiente Y y una o mas variables independientes X.

Simple (1 predictor):

ŷ = α + βx

Multiple (p predictores):

ŷ = β0 + β1x1 + ... + βpxp

Componentes:

α (β0): Intercepto — valor de Y cuando todas las X = 0
βj: Pendiente — cuanto cambia Y por cada unidad de cambio en Xj
ŷ: Valor predicho
ei = yi − ŷi: Residuo (error)

“Lineal” significa lineal en los parametros (β), no necesariamente en X. Puedes incluir X², log(X), interacciones, y sigue siendo regresion lineal.

Pobreza y focalizacion

Educacion

Predecir puntajes PISA, desercion escolar, efecto del gasto educativo. INEE/Mejoredu.

Salud publica

Predecir tasas de mortalidad, uso de servicios, gasto en salud por municipio.

Finanzas publicas

Predecir recaudacion fiscal municipal, transferencias federales, deuda publica.

Modelar tasas delictivas con variables socioeconomicas, densidad policial, urbanizacion.

En Mexico, la regresion lineal es la herramienta mas usada en evaluacion de politicas publicas, informes CONEVAL, Banxico y SHCP.

La funcion de costo (loss function)

¿Que significa “mejor recta”? La que minimiza el error entre valores reales y predichos.

MSE = (1/n) Σi=1n (yi − ŷi)²

Error Cuadratico Medio (Mean Squared Error)

¿Por que al cuadrado?

1. Elimina el signo (errores + y − no se cancelan)
2. Penaliza MAS los errores grandes
3. Es diferenciable y convexa → unico minimo global

OLS = minimizar MSE

Lo que aprendiste como OLS (Ordinary Least Squares) es exactamente minimizar MSE con forma funcional lineal.

Solucion analitica: β = (X'X)−1X'y

Conexion clave: Econometria y ML usan la misma matematica. La diferencia es el objetivo: econometria busca β insesgado (causal); ML busca ŷ preciso (prediccion).

Derivacion de α y β

Minimizamos S(α,β) = Σ(yi − α − βxi)² tomando derivadas parciales:

Derivada respecto a α:

∂S/∂α = −2Σ(yi − α − βxi) = 0

Σyi − nα − βΣxi = 0

α = ȳ − βx̄

Derivada respecto a β:

∂S/∂β = −2Σxi(yi − α − βxi) = 0

Sustituyendo α y simplificando:

β = Σ(xi−x̄)(yi−ȳ) / Σ(xi−x̄)²

β = Cov(X,Y) / Var(X) — La pendiente es la covarianza dividida entre la varianza. La recta siempre pasa por (x̄, ȳ).

Ver documento completo de derivacion: Derivacion_OLS.html

¿Por que es el modelo basico de ML?

La regresion lineal es la piedra angular de todo Machine Learning. Muchas tecnicas modernas se basan en sus principios:

1. Solucion analitica

Tiene formula cerrada (β=(X'X)−1X'y). No necesita iteracion. Base para entender metodos iterativos (gradient descent).

2. Interpretable

Cada β tiene significado directo. En ciencias sociales, la interpretabilidad es critica para politicas publicas.

3. Baseline universal

Todo modelo nuevo (random forest, redes neuronales) se compara contra regresion lineal. Si no la supera, no vale la pena.

4. Base de otros modelos

Logistica = regresion + sigmoid. Redes neuronales = regresiones apiladas. Lasso/Ridge = regresion + penalty.

5. Framework de evaluacion

MSE, R², train/test split, cross-validation: conceptos que nacen aqui y se usan en TODO ML.

6. Eficiente

Entrena en milisegundos. Con millones de datos, sigue siendo rapida. Ideal para prototipado.

¿Que significa R²?

El coeficiente de determinacion (R²) mide que proporcion de la variabilidad de Y es explicada por el modelo.

R² = 1 − SSres / SStot

SStot = Σ(yi − ȳ)²
Variabilidad total de Y

SSres = Σ(yi − ŷi)²
Variabilidad NO explicada (residuos)

SSreg = Σ(ŷi − ȳ)²
Variabilidad explicada por el modelo

Interpretacion:

R² = 0.85 significa que el modelo explica el 85% de la variabilidad de Y.

R² = 1: Prediccion perfecta
R² = 0: No mejor que predecir ȳ
R² < 0: Peor que predecir ȳ (posible en test)

R² ajustado: Penaliza por numero de variables. R²adj = 1 − [(1−R²)(n−1)/(n−p−1)]. Usar cuando comparas modelos con diferente numero de predictores.

Prediccion vs. inferencia
INFERENCIA (Econometria)

Objetivo: Estimar β insesgado

Pregunta: “Si educacion sube 1 ano, ¿cuanto sube el ingreso?”

Preocupacion: Sesgo de variable omitida, endogeneidad, causalidad

Evalua con: p-valores, intervalos de confianza de β

PREDICCION (ML)

Objetivo: Obtener ŷ preciso

Pregunta: “Dado este municipio, ¿cual sera su ingreso?”

Preocupacion: Overfitting, generalizacion a datos nuevos

Evalua con: RMSE, R² en datos de prueba

En politica publica necesitas ambas. Inferencia para entender por que. Prediccion para actuar que hacer. Este tema se enfoca en prediccion.

Variables categoricas

Cuando incluyes una variable categorica (ej. region: norte/centro/sur), R automaticamente la convierte en variables dummy (0/1).

Codificacion automatica:

Si region tiene 3 niveles (norte, centro, sur),
R crea 2 dummies:

regioncentro = 1 si centro, 0 si no
regionsur = 1 si sur, 0 si no

“norte” es la categoria de referencia (se omite).

Interpretacion de coeficientes:

regioncentro = -3.21
“Los municipios del centro tienen, en promedio, $3.21M menos de ingreso que los del norte, controlando por las demas variables.”

# En R: asegurar que sea factor datos %>% mutate(region = factor(region)) # lm() crea dummies automaticamente

¡No incluyas todas las dummies manualmente! Si tienes k categorias, R usa k−1 dummies. Si metes las k, hay multicolinealidad perfecta (la “trampa de las variables dummy”).

summary(), glimpse(), skim() — entender distribucion, detectar anomalias.

2

Manejar datos faltantes

Eliminar (na.omit()) o imputar (media, mediana, modelo). Ver siguiente slide.

Convertir categoricas a factor

mutate(region = factor(region)) — R necesita que sean factores para crear dummies.

4

Estandarizar (para regularizacion)

scale() o dejar que glmnet lo haga (standardize=TRUE). Critico si usas Ridge/Lasso.

5

Dividir en train / test

80% entrenamiento, 20% prueba. Nunca evaluar en train. Usar caret::createDataPartition().

Datos faltantes (NA)

Los NA son inevitables en datos sociales. lm() los elimina por defecto (na.action = na.omit), pero hay mejores opciones:

Opcion 1: Eliminar (listwise)

datos_limpios <- datos %>% drop_na()

Pierde observaciones. Riesgoso si los NA no son aleatorios.

Opcion 2: Imputar

datos_imp <- datos %>% mutate(across( where(is.numeric), ~ replace_na(., median(., na.rm = TRUE)) ))

Conserva observaciones. Mediana es robusta a outliers.

Recomendacion por tipo de faltante:

MCAR (Missing Completely at Random): Eliminar esta bien si son pocos.
MAR (Missing at Random): Imputar con mediana o modelo.
MNAR (Missing Not at Random): Problema serio. Consulta un experto.

El problema del sobreajuste

Un modelo puede ser perfecto en entrenamiento pero terrible en datos nuevos. Esto es overfitting.

ModeloR² TrainR² TestDiagnostico
OLS (50 variables)0.950.62Overfitting severo
OLS (6 variables)0.890.78Aceptable
Ridge (regularizado)0.840.82Excelente generalizacion

Senales de overfitting:
• R² train mucho mayor que R² test
• Coeficientes muy grandes o inestables
• Muchas variables, pocas observaciones

Solucion: Regularizacion
Penalizar coeficientes grandes para que el modelo sea mas simple y generalice mejor. Ridge, Lasso, Elastic Net.

Ridge Regression (L2)

Ridge agrega una penalizacion a la funcion de costo: penaliza coeficientes grandes.

LossRidge = MSE + λ Σj βj²

λ = parametro de regularizacion | Σβ² = suma de cuadrados de coeficientes

Que hace Ridge:

• λ=0: recuperas OLS
• λ pequeno: ligera contraccion
• λ grande: todos los β → 0
• λ→∞: predictor trivial (ŷ≈ȳ)

Todos los β se encojen, pero ninguno llega exactamente a cero.

Cuando usarlo:

• Multicolinealidad (variables correlacionadas)
• Quieres mantener TODAS las variables
• Mas observaciones que variables

Geometria: Busca β dentro de una esfera de radio ~1/λ.

Lasso Regression (L1)

Lasso usa valor absoluto en lugar de cuadrado. Esto tiene un efecto especial: algunos β se vuelven exactamente cero.

LossLasso = MSE + λ Σj |βj|

Ventaja: seleccion automatica

Lasso decide cuales variables son utiles. Las inutiles las elimina (β=0).

Con 50 variables, Lasso podria seleccionar solo 8.

Cuidado con la interpretacion

Que Lasso elimine una variable NO significa que no sea importante. Puede estar correlacionada con otra que Lasso conservo (redundancia, no irrelevancia).

Elastic Net combina Ridge + Lasso: Loss = MSE + λ(αΣ|β| + (1−α)Σβ²). Lo mejor de ambos: seleccion de variables + estabilidad.

Ridge y Lasso en R
library(glmnet) # Preparar matrices (glmnet no acepta formulas) X_train <- model.matrix(ingreso ~ ., data = train)[, -1] y_train <- train$ingreso # Ridge: alpha = 0 cv_ridge <- cv.glmnet(X_train, y_train, alpha = 0, nfolds = 5) plot(cv_ridge) # Curva de CV para elegir lambda ridge_best <- glmnet(X_train, y_train, alpha = 0, lambda = cv_ridge$lambda.min) # Lasso: alpha = 1 cv_lasso <- cv.glmnet(X_train, y_train, alpha = 1, nfolds = 5) lasso_best <- glmnet(X_train, y_train, alpha = 1, lambda = cv_lasso$lambda.min) # Ver coeficientes Lasso (cuales son 0?) coef(lasso_best) # Elastic Net: alpha = 0.5 cv_enet <- cv.glmnet(X_train, y_train, alpha = 0.5, nfolds = 5)

Loss = MSE + λΣβ²

Encoge todo, elimina nada

Lasso

Loss = MSE + λΣ|β|

Selecciona variables

Elastic Net

Loss = MSE + λ(αL1 + (1−α)L2)

Lo mejor de ambos

Como reportar resultados

Reportar una regresion de forma clara y profesional es una habilidad esencial:

En una tabla (estilo APA/academico):

• Coeficiente estimado (β)
• Error estandar (SE) o intervalo de confianza
• Significancia (estrellas o p-valor)
• R² y R² ajustado
• Numero de observaciones (n)
• F-statistic

# Tabla limpia con broom library(broom) tidy(modelo, conf.int = TRUE) glance(modelo)

En texto narrativo:

“Un modelo de regresion lineal multiple mostro que la tasa de educacion (β=0.89, SE=0.045, p<0.001) y el indice de ocupacion (β=0.34, SE=0.062, p<0.001) son predictores significativos del ingreso municipal. El modelo explica el 82% de la varianza (R²adj=0.822, F(4,495)=576.8, p<0.001).”

Errores comunes: No reportar n, no distinguir R² de R² ajustado, no indicar si es train o test, interpretar β como causal sin experimento.

Diagnosticos del modelo

Despues de ajustar el modelo, verifica que los supuestos se cumplan:

1. Linealidad

Residuos vs. valores predichos. Sin patron visible = OK. Patron curvo = relacion no lineal.

2. Homocedasticidad

Varianza constante de residuos. Si se “abre” en forma de abanico = heterocedasticidad.

3. Normalidad

Q-Q plot de residuos. Puntos sobre la linea = residuos normales. Menos critico con n grande.

4. Independencia

Residuos no correlacionados entre si. Critico en datos temporales (test de Durbin-Watson).

# Graficas de diagnostico con ggplot2 library(broom) diagnosticos <- augment(modelo) # Residuos vs. predichos diagnosticos %>% ggplot(aes(x = .fitted, y = .resid)) + geom_point(alpha = 0.4) + geom_hline(yintercept = 0, color = "red") + theme_minimal()
Validacion cruzada

¿Como elegir λ (o cualquier hiperparametro)? Nunca en test. Usamos cross-validation (CV).

■ Validacion   ■ Entrenamiento

Procedimiento: Para cada λ candidato, entrena 5 modelos (cada uno sin un fold), evalua en el fold dejado fuera, promedia MSE. Elige λ con menor MSE promedio.

cv.glmnet() automatiza todo esto.

Regla de oro: Train para entrenar. CV para elegir hiperparametros. Test SOLO al final, una vez. Si tocas test antes, tus metricas mienten.

Resumen: puntos clave
1

Regresion lineal busca la recta/hiperplano que minimiza el error cuadratico (MSE).

2

β = Cov(X,Y)/Var(X). Se obtiene derivando la funcion de costo e igualando a cero.

3

R² mide proporcion de varianza explicada. Usar R² ajustado para comparar modelos.

4

summary(): Estimate, Std.Error, t-value, p-value, R², F-statistic. Cada uno tiene significado.

5

Variables categoricas: R las convierte en dummies. Interpreta respecto a la referencia.

6

Ridge encoge coeficientes (L2). Lasso elimina variables (L1). Elastic Net combina ambos.

7

Regularizacion resuelve overfitting. Sacrifica precision en train, gana en test.

8

λ se elige con validacion cruzada. Nunca con datos de test.

9

Evaluar en test: RMSE, MAE, R². Siempre en datos virgenes.

10

Es el modelo basico de ML: interpretable, eficiente, base de todo lo demas.
