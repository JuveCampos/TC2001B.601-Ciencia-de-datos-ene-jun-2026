Derivacion de los coeficientes OLS

Obtencion de α (intercepto) y β (pendiente) a partir del problema de minimizacion de residuos

1. Planteamiento del problema

Supongamos que tenemos n observaciones de dos variables: una variable independiente x y una variable dependiente y. Nuestro objetivo es encontrar la recta que mejor se ajuste a estos datos:

ŷi = α + β xi

donde:

  • α (alpha) es el intercepto: el valor predicho de y cuando x = 0
  • β (beta) es la pendiente: cuanto cambia y por cada unidad de cambio en x
  • ŷi es el valor predicho para la observacion i

El residuo (error) de cada observacion es la diferencia entre el valor real y el predicho:

ei = yi − ŷi = yi − (α + β xi)

2. La funcion de costo: suma de residuos al cuadrado (SSR)

¿Que significa “mejor recta”? Queremos que los residuos sean lo mas pequenos posible. Para ello, definimos la funcion de costo (tambien llamada funcion de perdida o loss function):

S(α, β) = Σi=1n ei² = Σi=1n (yi − α − β xi)²

Nuestro objetivo es encontrar los valores de α y β que minimizan S(α, β).

¿Por que al cuadrado? Tres razones:
1. Elimina el signo: errores positivos y negativos no se cancelan.
2. Penaliza mas los errores grandes (un error de 10 pesa 100, un error de 1 pesa 1).
3. La funcion resultante es diferenciable y convexa, lo que garantiza un unico minimo.

3. Condiciones de primer orden

Para minimizar S(α, β), tomamos las derivadas parciales respecto a α y β, y las igualamos a cero:

Condicion 1:   ∂S / ∂α = 0

Condicion 2:   ∂S / ∂β = 0

4. Derivacion de α (intercepto)

Paso 4.1: Derivada parcial respecto a α

Aplicamos la regla de la cadena a S(α, β) = Σ (yi − α − βxi)²

∂S / ∂α = Σi=1n 2(yi − α − βxi)(−1)

La derivada de (yi − α − βxi) respecto a α es −1.

Paso 4.2: Igualar a cero y simplificar

−2 Σi=1n (yi − α − βxi) = 0

Dividimos entre −2:

Σi=1n (yi − α − βxi) = 0

Expandimos la suma:

Σ yi − nα − β Σ xi = 0

Paso 4.3: Despejar α

nα = Σ yi − β Σ xi

Dividimos entre n:

α = (1/n) Σ yi − β (1/n) Σ xi = ȳ − β x̄

donde ȳ = (1/n)Σyi es la media de y, y x̄ = (1/n)Σxi es la media de x.

Interpretacion: El intercepto α depende de β. Una vez que conocemos la pendiente, el intercepto se ajusta para que la recta pase exactamente por el punto (x̄, ȳ) — el centro de gravedad de los datos.

5. Derivacion de β (pendiente)

Paso 5.1: Derivada parcial respecto a β

∂S / ∂β = Σi=1n 2(yi − α − βxi)(−xi)

La derivada de (yi − α − βxi) respecto a β es −xi.

Paso 5.2: Igualar a cero y simplificar

−2 Σi=1n xi(yi − α − βxi) = 0

Dividimos entre −2:

Σi=1n xi(yi − α − βxi) = 0

Expandimos:

Σ xiyi − α Σ xi − β Σ xi² = 0

Paso 5.3: Sustituir α = ȳ − βx̄

Σ xiyi − (ȳ − βx̄) Σ xi − β Σ xi² = 0

Expandimos el termino central:

Σ xiyi − ȳ Σ xi + βx̄ Σ xi − β Σ xi² = 0

Recordemos que Σ xi = n x̄, asi que ȳ Σ xi = n x̄ ȳ y x̄ Σ xi = n x̄²:

Σ xiyi − n x̄ ȳ + β n x̄² − β Σ xi² = 0

Paso 5.4: Agrupar terminos con β

Σ xiyi − n x̄ ȳ = β (Σ xi² − n x̄²)

Paso 5.5: Despejar β

β = (Σ xiyi − n x̄ ȳ) / (Σ xi² − n x̄²)

6. Forma alternativa (mas intuitiva)

Podemos reescribir numerador y denominador en terminos de desviaciones respecto a la media. Esto es algebraicamente equivalente:

Numerador:

Σ xiyi − n x̄ ȳ = Σ (xi − x̄)(yi − ȳ)

Esto es la suma de productos cruzados de las desviaciones, tambien llamada Sxy.

Denominador:

Σ xi² − n x̄² = Σ (xi − x̄)²

Esto es la suma de cuadrados de las desviaciones de x, tambien llamada Sxx.

Formula final de β:

β = Σ(xi − x̄)(yi − ȳ) / Σ(xi − x̄)² = Sxy / Sxx
Conexion con la covarianza y varianza:

β = Sxy / Sxx = Cov(x, y) / Var(x)

La pendiente es la covarianza entre x e y dividida entre la varianza de x. Si x e y varian juntas positivamente, β > 0. Si x tiene mucha variabilidad, β se reduce.

7. Resumen de las formulas

Pendiente:
β = Σ(xi − x̄)(yi − ȳ) / Σ(xi − x̄)²

Intercepto:
α = ȳ − β x̄

Ecuacion de la recta:
ŷ = α + βx = (ȳ − β x̄) + βx = ȳ + β(x − x̄)

8. Condiciones de segundo orden (verificacion de minimo)

Para confirmar que es un minimo (y no un maximo o punto silla), verificamos la segunda derivada:

∂²S / ∂α² = 2n > 0     ✔

∂²S / ∂β² = 2 Σ xi² > 0     ✔

La matriz Hessiana es definida positiva ⇒ es un minimo global.

Conclusion

La funcion de costo S(α, β) es convexa (forma de parabola en dimensiones superiores), por lo que el punto critico encontrado es el unico minimo global. No hay otros minimos locales.

9. Extension al caso matricial (multiple regresion)

Cuando tenemos p variables predictoras (regresion multiple), el modelo es:

y = Xβ + e

donde X es la matriz de diseno (n × (p+1)), β es el vector de coeficientes, e y es el vector de respuesta.

El problema de minimizacion es:

minβ S(β) = (y − Xβ)′(y − Xβ)

Derivando respecto a β e igualando a cero:

∂S / ∂β = −2X′y + 2X′Xβ = 0

Resolviendo (ecuaciones normales):

β = (X′X)−1X′y

Esta formula es la generalizacion matricial. Cuando p=1, se reduce exactamente a las formulas de α y β que derivamos arriba.

Condicion necesaria: La matriz X′X debe ser invertible (no singular). Esto falla cuando hay multicolinealidad perfecta (una variable es combinacion lineal exacta de otras). La solucion: regularizacion (Ridge, Lasso).

Datos: 5 municipios con anos promedio de educacion (x) e ingreso per capita en miles de pesos (y):

Mediax̄=9ȳ=68

Calculo de β

β = Sxy / Sxx = 188 / 20 = 9.4

Calculo de α

α = ȳ − β x̄ = 68 − 9.4 × 9 = 68 − 84.6 = −16.6

ŷ = −16.6 + 9.4x

Por cada ano adicional de educacion promedio,
el ingreso per capita del municipio aumenta $9,400 pesos.

Verificacion en R

# Datos del ejemplo
x <- c(6, 8, 9, 10, 12)
y <- c(45, 55, 62, 78, 100)

# Calculo manual
beta <- sum((x - mean(x)) * (y - mean(y))) / sum((x - mean(x))^2)
alpha <- mean(y) - beta * mean(x)
print(c(alpha, beta)) # -16.6 9.4

# Verificar con lm()
modelo <- lm(y ~ x)
coef(modelo) # Intercept = -16.6, x = 9.4
